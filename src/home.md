# Home

Welcome to the documentation of Dicio, the *free software voice assistant for Android*. This website contains information on how to use specific **features of Dicio**, as well as **how to contribute** to its development, and how to do **maintainer tasks**.

### Project structure

- **Main repository** with Android App and skill interfaces: [dicio-android](https://github.com/DicioTeam/dicio-android)
- Domanin specific language and parser for **skill sentences**: [dicio-sentences-compiler](https://github.com/DicioTeam/dicio-sentences-compiler)
- Multilanguage **number parsing** and formatting library: [dicio-numbers](https://github.com/DicioTeam/dicio-numbers)
- Testing workbench to evaluate language matching algorithms: [dicio-evaluation](https://github.com/DicioTeam/dicio-evaluation)

### Editing this wiki

You can find the source code of this website [here](https://github.com/DicioTeam/docs). If you notice a mistake, or want to add a page with useful information, feel free to open a pull request. The policy for merging documentation PRs is to quickly take a look to ensure there are no major mistakes, but to otherwise trust the author and merge the pull request as soon as possible. This is to incentivize writing or amending documentation (just like on Wikipedia you can direclty edit pages).
